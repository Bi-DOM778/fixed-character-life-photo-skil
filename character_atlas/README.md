# Character Atlas Workspace

复制 sample 为实际 character-id 目录，按 [Atlas 文档](../docs/character_atlas.md) 放入已有身份图并填写清单。sample 为可安全发布的空图集，未包含任何真实人物图片。refs / candidates / approved_dataset 的 KEEP.md 说明用途，不是可选身份记录。

私有身份图、生成候选与运行记录建议放独立私有工作区；随包 [.gitignore](../.gitignore) 默认排除这些目录中的运行资产，保留说明文件。需要公开图集时由维护者主动选择有权发布的图片与元数据。
