# Consistency Ladder

按已观察失败逐级提升，不用增加提示词长度代替证据。

| 层级 | 触发 | 行动与完成证据 |
|---|---|---|
| 1 targeted correction | 单一眼距、轮廓、光线等缺陷 | 修一个主缺陷；记录 KEEP/CHANGE 与对比 QA |
| 2 atlas expansion | 对应角度/表情持续缺覆盖 | 新增必要视图候选，核对 master 并人工批准 |
| 3 approved dataset | 多场景重复使用、已有足够通过图 | 建议积累 10–20 张多角度/表情/光线验收图；保留来源与拒绝记录，不强制凑数 |
| 4 closest-reference routing | 图库扩大后选择低效或错误 | 用标签、角度、脸可读性路由；对同一目标比较路由前后漂移 |
| 5 optional LoRA / fine-tune | 充分 Atlas 与路由后仍在目标分布反复失败 | 用户另行选择支持训练的系统、数据与预算后评估；不得自动启动训练 |

v1.3 从第一天提供基础 Selector；层级 4 指在 approved dataset 上扩展覆盖与优化路由，不要求先积累 20 张才可选择参考。

进入下一层前记录 defect、已试 delta、参考覆盖、工具限制和三轴 QA。先检查路由错误、身份混入与图片质量，再决定是否需更多数据。新增图只因目标缺覆盖，而非每次失败都扩充。

训练是最后可选项，不随 ZIP 提供模型、训练能力或效果保证。使用有权使用的图像，保留独立未训练的验证视角；比较身份与场景泛化，避免把固定服装背景学成身份。训练失败不得放宽 anchor。
