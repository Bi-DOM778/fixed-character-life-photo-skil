# Expression Deformation — 保留身份，允许表情形变

适用于微笑、露齿笑、大笑、闭眼、眨眼、嘟嘴、惊讶、皱眉等目标。身份锁定保护这个人的基础结构，表情负责改变当下的肌肉状态；不能为了锁脸把表情冻结，也不能靠增加皮肤细节补救活人感。

## 三类变化分开判断

- **基础身份**：同一人的骨骼轮廓、五官相对布局、鼻部结构、唇部基础比例、下颌特征与成年年龄印象，依据已批准身份图。
- **表情形变**：眼睑开合、眉位、脸颊抬升或鼓起、嘴角位移、嘴宽变化、唇部压缩/拉伸/前突、下颌开合。允许其随目标表情联动，范围由目标参考和可观察状态决定。
- **相机投影与受光**：仰俯拍、头部旋转、距离、光线也会改变可见比例和轮廓。不能把这些变化机械判为换脸，也不能以透视为由容许无关身份漂移。

鼻部、嘴唇比例和下颌是重点身份证据，不是固定的二维模板。例如笑时鼻翼可能轻微变化，嘟嘴时唇部前突，张嘴时下颌位置改变；结合表情和视角判断是否仍属于同一张脸。禁止将眼睛放大、鼻形重设计、年龄改变或模板脸替换解释为自然形变。未知牙齿特征不得当成稳定身份标记。

## 把情绪写成可观察动作

| 目标 | 可以合理变化 | 常见失败 |
|---|---|---|
| 微笑 / 闭眼笑 | 嘴角上扬，脸颊抬升，眼裂收窄或自然闭合 | 只画上扬嘴角，眼颊不参与；把大方笑容缩成轻笑 |
| 露齿笑 / 大笑 | 嘴宽与开口扩大、牙齿可见、下颌下降、眼周随笑变化 | 平静脸贴一张张开的嘴；为锁唇形压制笑幅 |
| 眨眼 / 微眯 | 单侧眼睑闭合、局部眼周收缩，另一眼按目标微眯 | 左右反了；微眯变正常睁眼；无关重设计眼距 |
| 嘟嘴 / 飞吻 | 唇部前突、口角向内、脸颊按目标轻鼓 | 随意增加唇部体积，生成另一种嘴唇；嘴动但脸颊僵硬 |
| 惊讶 | 眉部抬升、眼睑张开、嘴部或下颌按目标打开 | 将睁眼幅度当成永久大眼美化 |
| 皱眉 / 委屈 | 眉间收缩、眼睑与嘴角配合目标情绪 | 为情绪新增永久皱纹、年龄或身份标记 |

只填写本次相关状态，不要求每次夸张表情。眨眼必须区分画面左/右与人物自身左/右；镜像未知时用画面方向说明，不擅自翻转。机位和头部姿态分开描述，抬下巴不能代替低机位。

## Stage A / B 的使用

1. 先记录目标表情、幅度、左右眼状态、眼颊嘴联动及头颈/身体配合。参考只提供目标状态，不提供人物身份。
2. 选同身份最近的已批准视角/表情图；缺表情图时，主图仍提供身份，目标表情允许自然形变，不据主图平静状态锁眼裂或嘴宽。
3. Stage A 校准身份时也保持目标表情幅度。可复用的批准图须适合本次状态；不必为每次表情新增图集。
4. Stage B 将该身份适配到场景动作、机位和受光。KEEP 保护基础身份与成功画面关系，CHANGE 写目标表情；不要把身份近景的灰背景光、平静眼神或克制笑容一起搬入生活照。
5. 当优质底图已有自然表现，优先保留表情联动与身体节奏再适配身份。若必须重建场景，独立报告随之改变的构图和动作。

## 可复制差量句

```text
KEEP: 批准身份图中的基础身份；按本次视角辨认鼻部结构、唇部基础比例、下颌和五官布局。保留场景的成功受光与身体动作。
CHANGE: 达到目标参考的表情幅度，允许眼睑、脸颊、嘴角、唇部和下颌随表情自然联动。目标为[表情]；画面左眼[状态]，右眼[状态]；嘴与脸颊[状态]；头颈/身体[配合]。
AVOID: 冻结主图平静表情，孤立修改嘴或眼，继承场景人物身份，靠新增毛孔/瑕疵/锐化补救僵硬。
SUCCESS: 同一身份可辨认，表情的类型与幅度到位，眼颊嘴和身体动作协调，人物受光与场景一致。
```

## 验收与返修

身份与表情分别检查。基础身份漂移为 Identity FAIL；身份接近但目标表情不充分或孤立僵硬为 Scene/Pose REVISE。不能互相抵消。闭眼、张嘴或遮挡使部分身份特征不可判断时记录 NOT-RUN，使用同身份补充参考检查可见结构，不虚报完整身份通过。

身份通过而表情失败时，下一轮只调整表情幅度/联动及必要姿态，保留成功身份、构图与光线；不增加毛孔、瑕疵或磨皮。沿用现有 Retry policy 与用户采纳门。本规范是提示与验收规则，不能保证模型精确身份迁移；实际效果须通过图片验证。
