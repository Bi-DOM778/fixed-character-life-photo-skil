# Identity Policy

## 身份契约

主身份参考是“这个人是谁”的唯一视觉来源。身份锁定包括：

- 脸部轮廓与比例；
- 眼形、间距与眼睑结构；
- 鼻梁、鼻翼与鼻尖关系；
- 唇形与上下唇比例；
- 下颌、年龄印象和自然不对称；
- 能够保留的真实皮肤纹理。

发型、表情、妆容和光线可变，但不得借此重设计身份。

身份契约描述的是基础结构，不要求不同表情下的二维轮廓、眼裂开度和嘴宽像素不变。按 [表情形变规则](expression_deformation.md) 区分肌肉形变、相机投影和真正身份漂移。鼻部、唇部基础比例、下颌作为重点证据也须在相应表情与视角下比较，不能机械锁定它们的投影。

## 参考职责隔离

| 输入 | 可贡献 | 不可贡献 |
|---|---|---|
| 主身份参考 | 身份结构、年龄印象、稳定特征 | 强制场景与姿势，除非用户要求 |
| 场景参考 | 姿势、构图、环境、光线、道具 | 人脸、种族特征、年龄、身体身份 |
| 文本要求 | 用户明确的可变目标 | 覆盖未经用户授权的身份变化 |

## 优先级与冲突

身份与风格冲突时保留身份；场景参考与用户文字冲突时以用户最新明确要求为准；多个身份参考明显不是同一人时停止身份合并并指出冲突。

## 失败条件

以下情况不得声称身份锁定成功：

- 没有身份参考；
- 参考图过度遮挡或分辨率不足以辨识核心结构；
- 多张参考图身份互相矛盾；
- 使用的生成系统不支持图像身份条件；
- 输出出现明显年龄、脸型或五官结构漂移。

## 美化边界

默认保留真实皮肤与年龄感。不得把“漂亮”自动解释为幼态化、过度磨皮、尖下巴、扩大眼睛或模板网红脸。若用户要求妆容变化，仍保持骨骼和五官比例稳定。

## v1.3 多视图身份来源

“唯一来源”指同一角色身份谱系，不限制为一张图。master 为裁决基准，approved Atlas 图提供投影证据；使用 [Anchor schema](../templates/character_identity_schema.md) 和 [Atlas](character_atlas.md)。场景人物体型不得补齐未知身体身份。
