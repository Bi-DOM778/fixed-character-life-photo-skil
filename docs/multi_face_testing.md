# Multi-face Testing — 多轮不同人脸测试

状态：PLANNED / NOT-RUN。此方案不是已通过的生图验证。需要用户提供或明确选定至少 3 位不同成年角色的身份图；每位角色单独建 identity、manifest 与记录，不混用 Atlas。可选择不同脸型、肤色、已有皮肤质感；无需推断族裔。

## 测试轮次

| 轮次 | 各角色的任务 | 核心判断 |
|---|---|---|
| R1 保留测试 | 同角度中近景，preserve；未见缺陷不加修正词 | 是否无故改变身份、肤色、柔润度或新增瑕疵 |
| R2 角度/表情 | 一次测试 45° 或微笑；有匹配 Atlas 则路由，无则记录 fallback | Selector、Anchor 与表情投影是否一致 |
| R3 场景迁移 | 窗光卧室、街头直闪、CCD 咖啡馆各一个目标 | 三轴 QA、不同摄影条件下的皮肤与全图协调 |
| R4 缺陷修正对照 | 只对真实出现缺陷的图做一次 targeted 编辑；原图作对照 | 缺陷是否改善，是否牺牲身份与原有美感 |

不存在明确缺陷的 R4 项标 N/A，不为了测试人为制造瑕疵。至少 3 位角色、每位 1 个 R1、1 个 R2 和 3 个 R3，形成 15 个基础目标；生成调用数取决于 A/B 复用与返修，不能把目标数当调用数。可先用第一位角色试跑，再继续其余角色，避免发现共同问题后仍完成整批。

## 公平对照与记录

同一目标对照固定身份输入、角度、表情、场景、画幅、工具/模型版本和可用参数；工具支持时保持种子一致，但不假称所有工具都可确定性复现。原图与修正版同尺寸并排检查全图，再检查脸部；放大仅辅助，不以放大毛孔数量评分。

记录原始输出，包括失败，不仅挑最好看的一张。对 targeted 修正先写 defect 与 delta；尽量一次调用，仅当工具失败或有具体可修原因时重试，遵守原有每目标 6 次调用与同缺陷 2 次重试上限。真实感退化时直接回退，不能为了“必须改善”耗尽预算。

## 结果与迭代

填写 [测试记录](../templates/multi_face_test_record.md)。Identity、Scene、Integration 分开报告；用户质感偏好为原图/修正版/相当，独立于身份门。NOT-RUN 与 N/A 不计通过率。各角色分别汇总，不用平均分掩盖某张脸持续失败。

身份硬失败、新增身份标记或用户认为质感明显退化时不能判整体 PASS。只出现于某场景的失败先修该场景条件，多个角色重复同一问题才考虑共享规则。每轮仅依据观察到的问题修订 Skill，记录版本后用同一失败目标复测，最后选此前未用的成年角色做留出测试。
