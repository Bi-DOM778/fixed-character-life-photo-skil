# Two-stage Pipeline

默认两阶段；已有适合本次角度/景别且身份 PASS 的 approved 底图可复用 Stage A。请求只要提示词时交付两个阶段的提示与未运行状态，不擅自宣称验收完成。

## Stage A — Identity Correct

输入 approved primary、必要 fullbody/expression 支持和 immutable anchor。先获得目标角度、表情、基本姿势与景别的可辨识人物，背景与光线尽量简洁，不加入复杂场景参考人物。

用 master 与最近视图检查身份；全身图需确认身体比例，脸太小则增加可辨识近景辅助检查或提高可用输出分辨率，不能因模糊而判 PASS。失败只修身份和相关角度控制，暂不执行 Stage B。

输出 A 图、来源与身份 QA。A 为临时身份通过候选，不自动具有 Atlas approval。

Stage A 同时保留目标表情的强度和联动关系，执行 [表情形变规则](expression_deformation.md)。简洁背景只是减少身份干扰，不把大笑改成轻笑、把眯眼改成正常睁眼或把动态表情改成证件照。只因已有主图身份通过，不代表其平静表情适合直接冻结到本次目标。

## Stage B — Scene / Outfit / Camera / Light

以 A 为编辑底图，保留 approved identity primary；输入路由明确的场景辅助图和五类锚点。只改变目标服装、环境、镜头与受光，保持 A 中成功的身份。目标与 A 角度严重不匹配时返回 Stage A，不能靠 B 随意重塑脸。

工具支持 mask 时用其限制服装/背景等编辑范围；全图重照明仍可能影响脸，须重新 QA。无 mask 时显式 KEEP 并记录 limitation，不承诺不可变像素。B 完成后三轴都须通过，身份不能仅沿用 A 的评分。

KEEP 锁定成功的身份基础，表情与姿态仍按目标调整。优质场景底图已有自然情绪时，保留其表情幅度、眼颊嘴联动、头颈与身体节奏，把固定身份适配进去；不继承场景人物五官。场景脸持续侵入时可改为身份图加文字重建，但必须重新验收因此改变的构图、姿态和受光，不能把身份改善视作整体通过。

## 工具降级

- 可编辑、多参考：A + primary +必要角色图；遵守容量并输出实际映射。
- 可编辑、单图：B 上传 A；身份图留作人工比较，场景辅助转文字，说明身份条件受限。
- 仅新生成：A 作视觉参考（如支持），重新生成 B，标记 regeneration，身份风险较高。
- 仅文本：输出分阶段 prompt 和 QA 目标，图像 QA NOT-RUN。

生成次数与修订预算见 QA Retry policy。预算用尽保留最后通过版本、失败缺陷和下一步所需参考，不将失败 B 覆盖已通过 A。

## Facial Realism 接入

Stage A 默认 preserve；Stage B 与返修按 [真实感修正](facial_realism.md) 处理观察到的缺陷。没有具体缺陷时保留原有质感。修正版变干杂、显老或身份改变时回退认可底图，不将退化图替换身份基准。
